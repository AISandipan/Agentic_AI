# 3. Test Copilot in Word

Open **Word** from Microsoft 365.

Create a new blank document.

Look for **Copilot** in the Word interface.

If it appears, try:

> Create a professional two-page project proposal for a Microsoft 365 implementation. Include objectives, scope, timeline, risks and next steps.

Copilot can then generate a draft that you can edit.

You can also select existing text and ask Copilot to:

* make it more professional

# 4. Set up Copilot in Excel

Open **Excel → New workbook**.

For example, create a table:

| Month    | Sales | Expenses | Profit |
| -------- | ----: | -------: | -----: |
| January  | 10000 |     6000 |   4000 |
| February | 12000 |     7000 |   5000 |
| March    | 15000 |     8000 |   7000 |

Then select your data and use **Copilot**.

You can ask:

> Analyze this data and identify the main trends.

Or:

> Create a summary of monthly sales and profit.

Or:

> Create a chart showing sales and profit by month.

Or:

> Identify unusual values or changes in this data.

Copilot in Excel has different experiences depending on your license and organization's configuration. ([Microsoft Support][4])

# 8. The really useful part: connect the Microsoft 365 ecosystem

This is where Microsoft 365 Copilot becomes much more useful.

Your work information can exist across:

**Outlook**
↓
Emails and calendar

**Teams**
↓
Chats and meetings

**OneDrive / SharePoint**
↓
Documents and files

**Word**
↓
Documents

**Excel**
↓
Business data

**PowerPoint**
↓
Presentations

With an appropriate Microsoft 365 Copilot license, Copilot can use organizational information that the user is permitted to access, while respecting Microsoft 365 permissions and organizational controls. ([Microsoft Support][5])

For example, instead of manually searching through emails, Teams and files, you could ask an appropriately licensed Copilot:

> Summarize everything I have access to about the ABC project and identify outstanding tasks.

The important qualification is **"everything I have access to."** Copilot does not give you permission to files or emails that your account couldn't already access.
