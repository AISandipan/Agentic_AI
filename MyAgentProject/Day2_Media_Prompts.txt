 ###  A useful formula pattern for your Copilot prompts

 You can also tell Copilot to generate formulas using this style:

```
=IF([@Status]="Completed",
   "COMPLETED",
   IF([@[Due Date]]<TODAY(),
      "OVERDUE",
      IF([@[Due Date]]<=TODAY()+2,
         "AT RISK",
         "ON TRACK"
      )
   )
)
```

 And for a **workflow completion percentage**:

```
=COUNTIF(tblWorkflow[Status],"Completed")/COUNTA(tblWorkflow[Story ID])
```

 For **average Time to Air**:

```
=AVERAGE(tblStories[Time to Air])
```

 For **dynamic overdue stories**:

```
=FILTER(tblStories,tblStories[Status]<>"Completed")
```

 For **rights expiring within 30 days**:

```
=FILTER(tblRights,
(tblRights[Rights Expiry Date]>=TODAY())*
(tblRights[Rights Expiry Date]<=TODAY()+30))
```
